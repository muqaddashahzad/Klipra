# CPU-only wheel index (--index-url https://download.pytorch.org/whl/cpu)
# BEFORE this requirements file, so they're already present when pip
# resolves ultralytics' dependency graph. Why split them out:
#   - Default torch wheels on aarch64 Linux pull ~2 GB of NVIDIA CUDA
#     libs (nvidia_cusparse, nvidia_cudnn, nvidia_cublas, ...). These
#     are useless on Mac (no GPU passthrough in Docker Desktop) and
#     one of them timing out is what was killing the build.
#   - The CPU-only wheels are ~200 MB total and have zero CUDA deps.
